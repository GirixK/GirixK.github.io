Minecraft Version 26.1

Default Java Version: Java 25

Recommended Java Version: Java 25


I haven't seen any benchmarks that really compare the following two GCs, theory states Shenandoah might be better,
but also I really recommend you try both of these setups out, and see which runs better for you

-XX:+UseShenandoahGC -XX:ShenandoahGCMode=generational -XX:+UseCompactObjectHeaders
-XX:+UseZGC -XX:+UseCompactObjectHeaders
